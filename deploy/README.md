# JANIT://SYS — API

The backend for [the portfolio site](https://jnt-h04.github.io/janit-portfolio/): FastAPI, serving the
profile data and the working demos.

| Endpoint | Demo |
| --- | --- |
| `/api/lexicon/*` | Book summarizer — chapter splitting and streamed summaries |
| `/api/fracture/*` | Concrete crack severity, from a fine-tuned ResNet50 |
| `/api/echo/*` | Meeting minutes from a recording |
| `/api/cortex/*` | Alzheimer MRI classifier — switched off in this deployment |
| `/docs` | The full API, browsable |

Source: https://github.com/JNT-h04/janit-portfolio
