# JANIT://SYS

A cyberpunk-themed portfolio where every project is a live, working demo rather than a description.

- `frontend/`: React + TypeScript + Vite, with Tailwind and Framer Motion
- `backend/`: FastAPI (Python), which serves the profile data and the ML demos

See [LEARNING.md](LEARNING.md) for how it fits together, how to run it, and the build missions.
